# Автобусы Подгорицы

Интерактивная карта городских автобусных маршрутов Подгорицы. На карте можно выбрать остановку, увидеть доступные линии и направления, открыть последовательность остановок по маршруту и найти ближайшие остановки по геопозиции.

## Источники данных

- [ePodgorica](https://epodgorica.me/javniprevoz/mapa) — названия, координаты и последовательность остановок, состав и направления линий.
- [Putevi DOO Podgorica](https://putevi.me/gradski-prevoz/aktuelni-red-voznje/) — опубликованный перечень действующих линий и направлений.
- [OpenStreetMap](https://www.openstreetmap.org/copyright) — картографическая подложка и дорожная сеть, © OpenStreetMap contributors, лицензия ODbL.

Данные сохранены как снимок на дату, указанную на странице. Геометрия маршрутов восстановлена вдоль дорожной сети по последовательности остановок, поэтому временные объезды и недавние изменения могут отличаться. Карта не показывает движение автобусов в реальном времени и не является официальным сервисом перевозчика.

## Публикация

Сайт состоит из статических файлов в корне репозитория и публикуется через GitHub Pages.
